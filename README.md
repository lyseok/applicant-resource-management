# Applicant-Resource-Management

### **📈 인프라 구축 부담 없이 채용 품질을 높이세요.**

후보자 발굴부터 내장된 온라인 시험과 화상 면접 기능까지, 채용에 필요한 모든 과정을 하나의 플랫폼에서 해결하여 시간과 비용을 절감하고 채용의 질을 높입니다.

### **🌱 공백기를 기회로, 프로젝트로 역량을 증명하세요.**

경력 공백기 동안 진행한 개인 프로젝트를 체계적으로 관리하고 포트폴리오로 구성하여, 실무 역량을 가장 투명하고 확실하게 증명할 수 있습니다.

### **☁️ All-in-One SaaS Platform**

설치가 필요 없는 SaaS 모델로, 기업과 구직자 모두에게 가장 효율적인 **성장의 기회**를 제공합니다.

# **📄프로젝트 소개**

저희는 복잡한 채용 과정과 경력 증명의 어려움을 동시에 해결하는 중소·스타트업을 위한 **채용-프로젝트 통합 SaaS**입니다. 하나의 플랫폼 안에서 후보자 발굴부터 온라인 시험·화상면접까지 **채용의 전 과정을 지원**하는 동시에, 구직자가 공백기 동안 진행한 **프로젝트를 체계적으로 관리하고 이를 실무 역량의 증거로 활용**할 수 있도록 돕습니다. 이를 통해 구직자는 프로젝트 기반의 포트폴리오로 자신의 잠재력을 투명하게 증명하고, 기업은 별도의 인프라 구축 부담 없이 내장된 기능만으로 **채용의 효율성과 품질을 극대화**할 수 있습니다.

# **🌟 주요 기능**

## **🔗 공용**

### 📝 **채용공고 상세**

- 공고정보: 제목·경력·급여·학력·근무지역, 상세 내용
- 접수: 접수기간, 지원방법
- 기업정보: 이름·대표자·업종·형태·주소

### 🏢 기업 상세

- **기업정보**: 개요/복지/뉴스/미디어
- **기업리뷰**: 현직·전직자 리뷰 요약
- **기업연봉**: 직무·연차별 연봉 정보
- **면접후기**: 난이도·질문·합격팁

## **👤 일반회원**

### 📄 이력서/자소서 관리

- **이력서**: 기본정보·경력·학력·스킬·경험·자격증·포트폴리오·어학·수상·병역, 대표이력서
- **자소서**: 자소서관리, 다중 문항 자소서

### 📨 지원 & 현황

- **지원**: 공고 지원, 첨부 관리
- **현황**: 단계별 진행(서류/시험/면접), 메일알림, 캘린더 일정조회

### 🔎 공고 탐색/추천

- **검색/필터**: 키워드·직무·지역
- **추천/저장**: 맞춤공고, 스크랩, 관심기업

### ⭐ **관심/스크랩**

- 관심기업: 관심기업 관리, 기업 일정 조회
- 공고스크랩: 공고 스크랩 관리, 공고 일정 조회

### 💬 프로젝트 공고

- 프로젝트정보: 프로젝트 주제, 기간, 소개
- 공고정보: 모집부문, 필요 기술
- 지원: 프로젝트 지원, 첨부 관리

### 📁 프로젝트

- 프로젝트개요: 설명, 상태, 기간, 진행률, 팀 멤버
- 작업: 칸반보드, 목록, 간트차트, 캘린더
- 대시보드: 작업 통계, 우선순위별 작업, 작업 내역 추적
- 그룹채팅: Stomp.js를 활용한 그룹채팅 구현

## **🏢 기업회원**

### 📢 채용공고

- **공고관리**: 등록/수정/삭제, 리스트/상세
- **시험관리**: 문제 관리, 응시 현황, 자동 채점
- **면접관리**: 문항 관리, 일정 관리, 오프라인/화상 링크, 결과 기록

### 🗓️ **일정**

- 일정관리: 채용 일정, 면접 일정, 시험 일정

### 🔍 인재풀 기능

- **인재탐색**: 조건/상세 검색, 필터(경력·스택·지역)
- **관심인재**: 관심 인재 목록, 대표 이력서 열람
- **입사제안**: 제안 메일 발송, 메일 템플릿 관리, 발송 내역

### 👥 지원자 관리

- **전형단계**: 서류 → 시험 → 면접, 상태 변경(보류/합격/불합격)
- **합격자관리**: 최종 합격 통보, 입사 일정·서류 안내
- **지원자평가**: 평가표·코멘트·점수, 다면 평가, 종합 랭킹

### 💳 **결제/멤버십/청구**

- 결제: 결제내역, 결제상태, 상세내역
- 멤버십: 등급, 인재풀 기능

### 📊 **기업 대시보드**

- 지원현황: 지원접수, 서류합격, 최종합격, 활성공고
- 인재풀: 총 구직자, 신규 가입자, 관심 인재
- 통계: 월별 신규 가입자, 인기 기술 스택
- 지원자통계: 연령대, 학력, 경력, 성별

### ⚙️ 기업 정보

- 기본정보관리: 대표자, 주소, 홈페이지URL, 업종, 주요사업, 로고 등
- 연봉관리: 최소/최대 연봉
